Chopper

A build guide for the day-time chopping mechanic in Unity.

What you are building

A small scene with a player capsule, a handful of tree cylinders, and a swing mechanic: walk into range, click, and a raycast checks whether you hit a tree. Each tree has a health value, and it disappears once that value hits zero. Everything here is blank shapes, the point is to prove the mechanic works before any art goes in.

Where this fits in the full design

This guide covers the day-time chopping mechanic, steps 1 through 4 below, which is phase 1 of a larger game: a hub with a pond, four elemental forests, and saplings that grow into tree enemies that come for the hut after dark. The tiered chopping built here, one hit for a small tree, two for medium, three for large, carries forward as-is into that full loop.

1

Block out the scene

Build every object with Unity's basic primitives first. Nothing needs final art yet, the goal is a scene you can test the mechanic in as fast as possible.

  • Ground. Right-click in the Hierarchy, choose 3D Object, then Plane. Set its position to (0, 0, 0).
  • Player. Right-click in the Hierarchy, choose 3D Object, then Capsule. Name it Player. Set its position to (0, 1, 0), so it rests on top of the ground.
  • Axe holder. Right-click the Player capsule and choose Create Empty. Name it WeaponHolder. Inside it, add a small Cube to stand in for the axe head, and move it forward so it sits roughly where a hand would hold it.
  • Tree. Right-click in the Hierarchy, choose 3D Object, then Cylinder. Name it Tree. Set its position to (0, 1, 0) as well.
  • In the Inspector, open the Tag dropdown at the top of the window, choose Add Tag, create a tag named tree, then come back and assign that tag to the Cylinder.
2

Camera and movement

For a fast third person setup, Unity's Character Controller component handles movement and collision without needing a Rigidbody.

  • Select the Player object, click Add Component in the Inspector, and add Character Controller.
  • Drag the Main Camera into the Player's hierarchy so it moves with the player, then position it slightly behind and above the capsule, looking over its shoulder.
  • Attach the script below to the Player.
PlayerMovement.cs
using UnityEngine;
public class PlayerMovement : MonoBehaviour { 
    public CharacterController controller; public 
    float speed = 6f; void Update() {
        float horizontal = 
        Input.GetAxisRaw("Horizontal"); float 
        vertical = Input.GetAxisRaw("Vertical"); 
        Vector3 direction = new 
        Vector3(horizontal, 0f, 
        vertical).normalized; if 
        (direction.magnitude >= 0.1f) {
            controller.Move(direction * speed * 
            Time.deltaTime);
            // Face the direction of movement, so 
            // the axe swings toward wherever the 
            // player is walking
            transform.rotation = 
            Quaternion.LookRotation(direction);
        }
    }
}
3

Write the chopping scripts

Two scripts: one holds a tree's health, the other handles the axe swing through raycasting, an invisible line cast forward from the player to check what it hits.

TreeHealth.cs, attach to the Tree cylinder
using UnityEngine;
public class TreeHealth : MonoBehaviour {
    // Customize hits per tree size: 1, 2, or 3
    public int maxHealth = 3; private int 
    currentHealth; void Start() {
        currentHealth = maxHealth;
    }
    public void TakeDamage(int damageAmount) { 
        currentHealth -= damageAmount; 
        Debug.Log(gameObject.name + " took damage, 
        current health: " + currentHealth); if 
        (currentHealth <= 0) {
            ChopDown();
        }
    }
    void ChopDown() {
        // For a greybox prototype, simply remove 
        // the tree. Later, spawn log items or 
        // play a fall animation here.
        Destroy(gameObject);
    }
}
AxeInteraction.cs, attach to the Player
using 
        UnityEngine;
public class AxeInteraction : MonoBehaviour { 
    public float attackRange = 3.0f; public int 
    chopDamage = 1; void Update() {
        if (Input.GetMouseButtonDown(0)) { 
            PerformChop();
        }
    }
    void PerformChop() { Ray ray = new 
        Ray(transform.position, 
        transform.forward); RaycastHit hit; if 
        (Physics.Raycast(ray, out hit, 
        attackRange)) {
            if (hit.collider.CompareTag("tree")) { 
                TreeHealth tree = 
                hit.collider.GetComponent(); 
                if (tree != null) {
                    tree.TakeDamage(chopDamage);
                }
            }
        }
    }
}

Fix

The original guide suggested attaching this script to either the Player or the WeaponHolder. Attach it to the Player instead. Since the movement script now rotates the Player object itself, transform.forward on the Player matches the direction it is walking. If this script sits on WeaponHolder instead, the swing direction depends on WeaponHolder's own local rotation staying untouched, which is an easy thing to break later without noticing.

4

Test the loop

  • Duplicate the Tree cylinder a few times and scatter the copies around the plane.
  • In each tree's Inspector, set Max Health on the TreeHealth component, for example 1 for a small tree, 2 for medium, 3 for large.
  • Press Play.
  • Walk up to a tree and left click. Watch the Console tab, the health count should drop with each swing and the tree should disappear at zero.

Test this from a few different approach angles, not just walking straight at a tree. If chopping only works when you approach from one particular direction, the rotation fix in step 2 did not get applied correctly.

Where this goes next

Once the loop holds up from every angle, phase 1 is done. The development plan lays out the rest in full, in short:

  • Wood pickups, and hauling wood back to the hub.
  • Saplings that drop from chop hits and carry over into the night.
  • A day and night cycle that turns those saplings into tree enemies.
  • Hut health, repair, and defense against enemies that reach it.
  • Elemental zones and the buffs earned from killing elemental enemies.
  • Boss saplings, and the encounter that follows once one matures.

The full picture, the hub, the four zones, and how the elements and buffs work, is in the game design document.
